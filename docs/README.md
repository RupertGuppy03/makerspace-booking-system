# docs/

Design and reference notes for the project. Written for each other, not for a marker — keep it
short and update it when the code changes.

| File | Covers |
|---|---|
| `architecture.md` | How frontend, backend and Supabase fit together |
| `api.md` | REST endpoints — path, method, request/response shape |
| `db-schema.md` | Tables, columns, relationships |
| `auth.md` | How login works and how the backend validates JWTs |
| `dev-setup.md` | Step-by-step setup for a new machine |

Add diagrams as images or mermaid blocks. If a decision took a discussion to reach, write down
*why* — that's the bit people forget.
