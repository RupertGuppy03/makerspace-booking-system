# src/types/

Shared TypeScript types. Mostly mirrors of the C# models the API returns.

```
tool.ts          → Tool
reservation.ts   → Reservation
user.ts          → User
```

## Rules

- These must match the backend. If someone changes a C# model, the matching type here changes in
  the same PR.
- C# `PascalCase` properties usually serialise to `camelCase` JSON — type what the API actually
  sends, not what the C# class looks like.
- Use `type` for object shapes, `interface` only when you need to extend.
- No `any`. If you don't know the shape yet, use `unknown` and narrow it.

Page-specific types that nobody else uses can just live in your page file.

## Other Notes

Separate 'normal' and 'new' types exist for each type.
Normal types include the ID and are used when data is recieved from the backend.
New types omit the ID and are used when created a new object to be POSTed. The ID will be auto generated by the database

'new' types are the same as the normal ones but do not contain an attribute for id or foriegn key relationships (but still the foreign key id). They are used when creating a new object to be sent to the API.
